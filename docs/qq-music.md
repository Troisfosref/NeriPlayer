# QQ 音乐接入

本补丁基于 `Troisfosref/NeriPlayer` 的 `ebaecd6b70bbe0d7d6a5d24df93c3e23f6e8df2d`。

## 使用

1. 打开“设置 → 第三方平台登录 → QQ 音乐”。
2. 使用手机 QQ 扫描二维码并确认，或粘贴包含音乐账号 ID 和音乐登录凭据的 Cookie。
3. 在“设置 → 音质设置 → QQ 音乐默认音质”选择标准（128 kbps）、高品质（320 kbps）或无损。
4. 在探索页选择 QQ 音乐并输入歌名或歌手。支持分页加载、混合队列、加入本地歌单、歌词和下载。
5. QQ 歌曲的 `https://y.qq.com/n/ryqq/songDetail/MID` 与含 `songmid` 的网页链接可用于链接识别。

在线播放和下载使用平台为当前账号签发的票据。高档位没有可用完整音源时，依次尝试较低档位。
播放页显示实际解析到的档位，并复用原生音质切换菜单。设置页和播放页共享偏好，修改后按原刷新流程保留进度。
流量音质与下载音质均进入现有设置分组；已有歌曲缓存按首选档位区分。

账号凭据使用独立的 Android 加密存储，不进入歌单、历史、同步文件或分享链接。
扫码会话只存于当前面板内存中；关闭面板停止轮询，应用进入后台也暂停轮询。
QQConnect 的临时票据按域名、路径和有效期隔离；同名的过期 Cookie 不会覆盖其他域名下的有效票据。
刷新二维码会创建独立会话，临时扫码 Cookie 不会写入音乐账号凭据。

扫码确认后若仍失败，错误后会附简短编号：`QQ-01` 为状态查询，`QQ-02` 为登录票据，
`QQ-03` 为授权会话激活，`QQ-04` 为 OAuth 授权，`QQ-05` 为音乐账号换票。
编号不包含 Cookie 或授权码，反馈问题时可提供该编号。

## 接入范围

已接入 QQ 扫码和 Cookie 登录、歌曲搜索、歌曲详情、完整音源解析、标准 / 高品质 / 无损降档、
来源标识、歌词与翻译、本地歌单、下载及歌曲链接分享。

已接入账号昵称、头像与 ID、我喜欢的音乐、创建和收藏的云端歌单，以及每日推荐、猜你喜欢和推荐歌单。
首页展示个性化推荐；媒体库新增并列的 QQ 音乐分类，歌单详情支持分页及完整加载后播放全部。
播放页支持明确写入 QQ 云端我喜欢；自动双向同步、普通云端歌单编辑、微信 / 短信登录、登录自动续期及一起听尚未接入。
QQ 歌曲会从一起听分享队列中排除，避免被当作网易云歌曲处理。

## 实现

- `modules/model/.../qqmusic/QQMusicSongRef.kt`：目录 MID 和媒体文件 MID 分离，不使用兼容长整型 ID 请求平台接口。
- `modules/platform/.../qqmusic/api`：客户端协议、播放票据、音质规格和响应校验。
- `modules/platform/.../qqmusic/auth`：QQConnect OAuth、扫码会话和独立加密凭据。
- `modules/platform/.../qqmusic/QQMusicRepository.kt`：歌曲映射、分页、串行换票和音质降档。
- 宿主通过播放器、下载器已有接口接入，复用现有的本地歌单、队列、歌词解析和存储。

请求格式及 OAuth 顺序参考 MusicOne QQ 音源，来源与许可证见 `THIRD_PARTY_LICENSES.md`。

## 原生界面

QQ 首页复用现有歌曲分页列表与歌单卡片；歌单使用现有详情页框架、搜索、播放控制、歌曲行和菜单。
详情通过常规导航打开，保留主界面的迷你播放器和底部导航。
“设置 → 首页与启动 → QQ 音乐推荐”独立控制首页展示，关闭后停止加载 QQ 推荐，媒体库仍可使用。
网页兼容播放请求不携带移动端专用参数；同档位 URL 不匹配时继续兼容换票，全部失败后重新取得一次媒体 MID。

## 完整音源验证

播放先按 MusicOne 的 `music.vkey.GetVkey/UrlGetVkey` Android 信封取票，再尝试网页兼容请求；
云端已有的标准 Vkey 与 EVkey 仍作为后备。响应同时读取 `purl` 和 `wifiurl`。
`src` 参数不再直接等同于试听：标记地址需检查音频格式及真实时长，误差限为 2 秒或总时长的 2%。
无损先读取 42 字节 FLAC STREAMINFO，其他情况使用 Android MediaExtractor。
只有确认时长完整的地址才可播放；无法确认或短试听继续取票、降档。
单次解析复用已检查结果，媒体探测不携带账号 Cookie。

清理了未使用的 QQ“开发中”占位页；媒体库收藏来源使用 QQ 音乐名称。
首页和媒体库分别按需加载，歌单详情不再触发整套推荐/账号列表请求。

## 分类搜索

QQ 搜索提供歌曲、专辑、歌手和歌单四种分类，使用与网易云相同的分类按钮与结果行。
分类独立参与搜索取消、分页去重和滚动位置重置，切换分类不会混入旧请求的结果。
按 MusicOne 的 Desktop 搜索信封取数，歌曲搜索仍保留原可用接口作为后备。
专辑与歌单打开共用详情框架；歌手打开热门歌曲列表，均支持已有播放、导出和批量下载操作。
专辑与歌手使用独立的 ID 前缀及专用分页接口，不当作 QQ 云端歌单收藏。

QQ 专辑详情右上角提供与歌单相同的收藏/取消收藏按钮，收藏显示在“媒体库 → 收藏”。
专辑使用独立收藏来源与稳定存储键，并保留原始 MID；从收藏打开时仍走专辑接口，
不与普通 QQ 歌单的数字 ID 混用。沿用已有收藏存储及同步机制。
